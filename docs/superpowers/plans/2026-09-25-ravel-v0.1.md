# Ravel v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Ravel v0.1 into a reproducible research instrument that can inspect one agent skill, execute it through the controlled Ravel Runner inside a rootless Podman sandbox, record evidence, verify its own instrumentation, and produce machine- and human-readable experiment reports.

**Architecture:** Ravel is a TypeScript/Node.js CLI composed of isolated modules for skill inspection, experiment orchestration, sandbox management, the controlled Runner, instrumented tools, policy evaluation, trace recording, observation derivation, and reporting. Runtime behavior flows through Ravel-owned tools and policy before affecting the disposable sandbox so attempted, permitted, denied, and resulting behavior remain separately observable.

**Tech Stack:** TypeScript, Node.js, npm, Vitest, Commander, Zod, YAML, gray-matter, OpenAI JavaScript SDK, OpenAI Responses API, rootless Podman, JSONL, JSON, static HTML.

**Spec:** `docs/superpowers/specs/2026-09-25-ravel-design.md`

## Global Constraints

- Study 001 uses the Ravel Runner, not Codex, Claude Code, or another external agent host.
- One fixed model provider and model configuration is used for Study 001.
- Study 001 model: `gpt-6-sol`.
- Model rationale: as verified against current official OpenAI documentation on 2026-09-25, GPT-6 Sol supports the Responses API and function calling and is positioned for complex coding and agentic workflows with a capability/cost balance appropriate to a fixed research Runner.
- Study 001 compares one coherent skill family.
- Fixture, task wording, permissions, limits, Runner version, container image, and model configuration remain constant between compared skills.
- Rootless Podman provides the disposable execution environment.
- Real user home directories, credentials, SSH keys, browser data, and unrelated host paths are never mounted into experiments.
- Experiment credentials and canaries are synthetic only.
- Network access is denied by the Study 001 baseline policy, while attempted access remains observable.
- Structured `run_process(program, args, cwd)` is the default process interface; unrestricted shell strings are not exposed.
- Ravel reports measurements and provenance, not a safety/trust score.
- Deliberate prompt injection is excluded from Study 001.
- Raw evidence flows `trace.jsonl → report.json → report.html`.
- Study data is not considered valid until `ravel verify` passes under the same relevant instrumentation configuration.
- No GUI, accounts, cloud service, MCP auditing, multi-host comparison, multi-model comparison, or CI integration in v0.1.

## Review Focus

1. **Filesystem traversal and symlink escape:** paths such as `../protected`, nested traversal, and symlinks pointing outside `/workspace` must not bypass policy.
2. **Malformed or hostile skill structure:** missing references, cyclic local references, invalid frontmatter, unreadable files, and oversized files must fail predictably before execution.
3. **Interrupted experiments:** model errors, Podman failures, process timeouts, and step limits must preserve partial evidence and clean up the sandbox.
4. **Trace/report divergence:** every derived count and comparison must be reproducible from real event IDs in `trace.jsonl`.
5. **Untrusted tool arguments/output:** malformed arguments, oversized files, excessive process output, and unsupported network URLs must be rejected or truncated deterministically and recorded.

# v0.1 Completion Gate

Ravel v0.1 is complete only when all of the following are simultaneously true:

```text
ravel inspect <valid-skill>
→ produces conservative static analysis

ravel verify
→ Instrument verification passed.

ravel run <controlled-review-skill>
→ creates complete evidence bundle

sandbox
→ destroyed after experiment

trace.jsonl
→ passes integrity validation

report.json
→ contains only evidence-backed observations

report.html
→ reflects report.json without independent claims

real host files / secrets
→ unavailable to experiment

Study 001
→ has a frozen pilot protocol
```

The first release does **not** require the full Study 001 dataset or article to be complete.

The software milestone is reached when Ravel can reliably conduct and document one reproducible experiment end-to-end.
