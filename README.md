# Ravel 🧶

Ravel is an experimental toolkit for studying how AI coding agents behave when given structured skills and instructions.

It runs tasks inside controlled, isolated environments and compares what an agent **says it will do** with what it **actually does**.

## Status

🚧 Early development.

The first study focuses on **Declared vs. Observed Behavior**.

## Built with

- TypeScript
- Node.js
- Podman

## Why Ravel?

AI agent behavior can get tangled.

Ravel helps pull the threads apart.
